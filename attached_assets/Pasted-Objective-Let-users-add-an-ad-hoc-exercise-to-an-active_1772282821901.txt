Objective

Let users add an ad-hoc exercise to an active workout session from SessionRunScreen. The user picks a name, mode (strength/distance/interval/time/notes), and for strength, a set count. The exercise is session-only — it is not saved back to the program template.

Design

"+" icon button added to the navigation header (right side, alongside the existing "Finish" button — Finish moves slightly left)
Tapping "+" opens a bottom-sheet-style Modal with:
Text input: exercise name
Mode selector: 5 pill buttons (Strength / Distance / Interval / Time / Notes)
Set count row (only shown for Strength): "–" / number / "+" to pick 1–10 sets, default 3
"Add to Workout" primary button — disabled if name is empty
"Cancel" secondary link
On confirm:
Generate a local UUID for the task (prefixed adhoc- for traceability)
Build a TaskTemplate-shaped object in memory (no taskTemplatesStorage.create call)
Build the initial TaskLogState for it:
Strength: { sets: Array(setCount).fill({ setNumber, weight: undefined, reps: undefined, isCompleted: false }) }
All others: empty data: {}
Append both to tasks and taskLogs state
Set currentTaskIndex to the new task's index so the user lands on it immediately
